# Traces of Pain guide

Visitor guide web app for the exhibition *Traces of Pain* by Gabriel Matula.

## Zoom images

Full screen shows `img/full/<id>.jpg` (1800 px). When a visitor zooms in past ~1.3x, the viewer
swaps in `img/zoom/<id>.jpg`, the original resolution (Gabriel's files, about 2500 px, JPEG q86).
When adding new photos, save the original-size file to `img/zoom/` with the same name. A photo
without a zoom file still zooms, just using the 1800 px image.
