# Licensed fonts

The guide uses three commercial typefaces chosen by Gabriel. Put their web font files here
(only with a licence that allows web use) and they load automatically:

| Use | Font | File name expected |
|---|---|---|
| Main titles | Spalla Semibold | `Spalla-SemiBold.woff2` |
| Smaller titles | Athelas Regular / Italic | `Athelas-Regular.woff2`, `Athelas-Italic.woff2` |
| Texts | DIN 2014 Light / Regular / Bold | `DIN2014-Light.woff2`, `DIN2014-Regular.woff2`, `DIN2014-Bold.woff2` |

Devices that already have a font installed use it without these files (iPads and Macs have Athelas).
Until a file is here, the guide falls back to free look-alikes from Google Fonts:
Italiana (titles), EB Garamond (smaller titles) and Barlow (texts).
