Sign in to edit the guide

Saving writes your changes to the GitHub repository, and the live guide updates about a minute later. To allow that, paste a GitHub access key. You only do this once on each device.

  1. Open New fine-grained token on GitHub (signed in as the repo owner or a collaborator).
  2. Name it "Guide admin". Under Repository access choose Only select repositories and pick traces-of-pain-guide.
  3. Under Permissions → Repository permissions, set Contents to Read and write.
  4. Click Generate token, copy it, and paste it here.
